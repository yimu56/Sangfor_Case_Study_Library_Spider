# 深信服案例库爬虫 (Sangfor Case Study Library Spider)

一个运行在浏览器里的 **用户脚本（Userscript）**，用于批量抓取深信服官方知识库
[`support.sangfor.com.cn`](https://support.sangfor.com.cn) 的案例库（案例 / 解决方案）。
支持按产品线、模块、版本、关键词筛选，并发翻页抓取列表与正文，并还原
「问题描述 / 根因 / 解决方案」的章节结构与配图，最终可一键导出为
**单文件 HTML / Markdown / CSV / JSON**。

> 脚本基于浏览器登录态运行 —— 不需要账号密码，只要你在浏览器里已经登录了深信服支持网站即可。

---

## 功能特性

- **多维筛选**：按产品线、主/子模块、适用版本、关键词组合筛选目标案例。
- **并发翻页抓取**：列表与正文均采用可控并发 + 请求间隔，稳定不卡死。
- **章节结构还原**：案例正文的章节标题（如「问题描述」「根因」「解决方案」）藏在
  TinyMCE 只读输入框里，脚本用 DOM 解析还原层级，而不是简单去标签丢结构。
- **配图处理**：`link` 模式保留原图外链；`embed` 模式把图片下载为 base64 内嵌，导出的文件可离线阅读。
- **面板默认最小化**：脚本启动后面板以收起状态挂在右下角，标题栏实时显示抓取进度；
  需要时点标题栏的 `□` 展开。可在面板里取消「启动时默认收起」。
- **四种导出格式**：
  - `HTML`：单文件、内部自带分页，正文与图片按需渲染（滚动到哪加载哪），
    几百条也不卡；可直接浏览器打开或「打印为 PDF」。
  - `Markdown`：含目录、章节、配图，便于二次编辑。
  - `CSV`：带 UTF-8 BOM，Excel 直接打开不乱码。
  - `JSON`：保留全部原始字段，便于程序化处理。
- **断点续爬**：开启 `resume` 后中断可从断点继续；支持「按更新时间过滤」（近 7/30/90 天）。
- **HTML 分卷**：数据量大时可按条数自动分卷导出，避免单个文件过大。

## 环境要求

| 项目 | 说明 |
| --- | --- |
| 浏览器 | Chrome / Edge / Firefox 等现代浏览器 |
| 用户脚本管理器 | [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) |
| 登录态 | 浏览器需已登录 `support.sangfor.com.cn`（脚本借用当前会话 Cookie 调内部 API） |

---

## 安装

1. 给浏览器装上 Tampermonkey 或 Violentmonkey 扩展。
2. 打开脚本文件
   [`sangfor-case-crawler.user.js`](./sangfor-case-crawler.user.js)，
   或用管理器「新建脚本」后把内容整段粘贴进去保存。
3. 也可直接把该 `.user.js` 文件拖入管理器窗口完成安装。
4. 安装后访问 `support.sangfor.com.cn` 任意案例相关页面，脚本会自动注入浮动面板。

---

## 使用步骤

1. **确认登录**：在浏览器里登录 `support.sangfor.com.cn`（脚本面板里点「测试连接」可验证会话是否有效）。
2. **打开面板**：脚本就绪后右下角会出现浮动面板；也可通过管理器菜单
   「打开/关闭 案例爬虫面板」切换显示。
3. **设置筛选条件**：选择产品线、模块、版本，填写关键词；也可直接在页面自带搜索框输入，会与面板双向同步。
4. **预搜索（可选）**：点面板上的「🔍 搜一下」查看命中范围，确认筛选无误。
5. **开始抓取**：点「▶ 开始抓取」。抓取过程中可「暂停 / 停止」；面板实时显示进度
   （列表页数、案例条数、正文完成数）。
6. **导出结果**：抓取完成后，在面板选择导出格式（HTML / Markdown / CSV / JSON）即可下载。

> 管理菜单里的「清空断点缓存」用于清除本地续爬缓存（断点数据存于 `localStorage`）。

## 配置项说明

脚本顶部的 `defaults` 对象集中了运行参数，可在脚本里按需调整：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `productLineId` | `''` | 产品线 ID（空 = 全部） |
| `keyword` | `''` | 关键词（标题 / 模块等） |
| `mainModuleIds` | `[]` | 主模块 ID 列表 |
| `childModuleIds` | `[]` | 子模块 ID 列表 |
| `versionId` | `''` | 适用版本 ID |
| `pageSize` | `20` | 每页条数 |
| `maxPages` | `0` | 最大翻页数，`0` = 抓取全部 |
| `concurrency` | `3` | 列表并发数 |
| `interval` | `400` | 请求间隔（毫秒），用于限速 |
| `fetchDetail` | `true` | 是否抓取案例正文详情 |
| `detailConcurrency` | `4` | 正文并发数 |
| `resume` | `false` | 断点续爬开关 |
| `onlyRecent` | `''` | 按更新时间过滤：`'7d'` / `'30d'` / `'90d'` / `''` |
| `imageMode` | `'link'` | `'link'` 保留外链 / `'embed'` 内嵌 base64（离线可用） |
| `htmlPartSize` | `0` | HTML 分卷大小（每条文件多少条），`0` = 单文件 |
| `startMinimized` | `true` | 面板启动时默认收起为最小化（面板内可取消，会记住选择） |

---

## 导出字段

CSV / JSON 导出的结构化字段包括：`案例ID`、`源ID`、`标题`、`产品线`、`主/子模块`、
`适用版本`、`架构版本`、`创建/更新时间`、`详情页链接`、`列表摘要`，以及正文三态
（`Markdown` / `纯文本` / `HTML`）。
